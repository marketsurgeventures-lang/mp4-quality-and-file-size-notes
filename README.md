# MP4 Quality and File Size Notes

These notes explain how MP4 resolution affects quality and storage. For more MP4 guides and tools, see [Youtube 2 MP4](https://yt2mp4.live/). The advice below applies to any video you have the right to save.

## Resolution at a glance

360p is the smallest practical size and works on slow connections. 480p is a step up for small screens. 720p balances sharpness and size for phones. 1080p is the usual choice for laptops, tablets and TVs.

## Why file size changes

File size depends on resolution, length and bitrate. A short clip at 720p is small, while a long video at 1080p can take a lot of storage.

## Offline viewing tips

Save videos on a stable connection, keep files in clearly named folders, and delete old files to free space before a trip.

## Stay within the rules

Only save content you own, have permission to use, or that is openly licensed.
